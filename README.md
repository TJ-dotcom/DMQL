## Overview

This dataset is intended for use with a PostgreSQL database and consists of several CSV files that represent different entities in a library management system. The data is organized into tables such as Authors, Publishers, Books, Users, and more.

## CSV Files

- **Authors.csv**: Contains information about authors, including `author_id` and `name`.
- **Publishers.csv**: Contains information about publishers, including `publisher_id` and `name`.
- **Genres.csv**: Contains information about book genres, including `genre_id` and `name`.
- **Languages.csv**: Contains information about languages, including `language_id` and `name`.
- **Addresses.csv**: Contains address details, including `address_id`, `street`, `city`, `state`, and `zip_code`.
- **Books.csv**: Contains book details, including `book_id`, `title`, `isbn`, `publication_year`, `author_id`, `publisher_id`, `genre_id`, and `language_id`.
- **Users.csv**: Contains user information, including `user_id`, `name`, `email`, `phone_number`, and `address_id`.
- **Book_Copies.csv**: Contains information about book copies, including `copy_id`, `book_id`, `status`, and `address_id`.
- **Loans.csv**: Contains loan details, including `loan_id`, `user_id`, `book_id`, `checkout_date`, and `due_date`.
- **Staff.csv**: Contains staff information, including `staff_id`, `name`, `position`, and `address_id`.
- **Library_Branches.csv**: Contains branch details, including `branch_id`, `name`, and `address_id`.
- **Events.csv**: Contains event details, including `event_id`, `branch_id`, `name`, and `date`.
- **Fines.csv**: Contains fine details, including `fine_id`, `loan_id`, and `amount`.
- **Book_Reviews.csv**: Contains book review details, including `review_id`, `book_id`, `user_id`, `rating`, and `review_text`.

- **Reservations.csv**: Contains reservation details, including `reservation_id`, `book_id`, `user_id`, and `reservation_date`.

## Loading Data into PostgreSQL

The data has been uploaded manually to the tables by just selecting the import option by right clicking the table and then choosing the path for csv files. Alternatively the data could be uploaded bulk through the terminal starting from the tables with no dependencies.
